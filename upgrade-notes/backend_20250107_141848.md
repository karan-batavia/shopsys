#### remove linked categories on category edit/create from administration ([#{3718}](https://github.com/shopsys/shopsys/pull/3718))

- The "Linked Categories" functionality has been completely removed from the administration:

    - class `App\Form\Admin\CategoryFormTypeExtension` was removed
    - The setting is no longer available during category creation or editing
    - If your project uses this functionality, do not apply the migration and consider implementing this feature directly within your project

- see #project-base-diff to update your project
